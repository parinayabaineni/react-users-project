# React Users Directory

A simple React project that fetches user information from JSONPlaceholder and displays it in responsive cards.

## Requirements

- Node.js and npm
- Internet connection to fetch the sample user data

## Run locally

1. Extract this ZIP file.
2. Open the extracted folder in VS Code.
3. Open the terminal in the project folder.
4. Run:

```bash
npm install
npm run dev
```

5. Open the local URL shown in the terminal (usually `http://localhost:5173`).

## Upload to GitHub


```bash
git init
git add .
git commit -m "Add React users directory"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/YOUR-REPOSITORY.git
git push -u origin main
```

Replace the example GitHub URL with your own repository URL.
